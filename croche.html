Flor de Crochê

Uma flor delicada para decorar suas peças.

Clique para ver o tutorial ↓

🧶 Tutorial: Flor de Crochê

Materiais

  • Linha de crochê
  • Agulha de crochê
  • Tesoura
  • Agulha de tapeçaria

Passo a passo

  1. Faça um círculo mágico.
  2. Faça pontos baixos dentro do círculo.
  3. Faça os pontos necessários para formar as pétalas.
  4. Continue fazendo as pétalas até completar a flor.
  5. Arremate e esconda o fio.

Clique para ver o tutorial ↓

🧸 Tutorial: Amigurumi

Materiais

  • Fio para amigurumi
  • Agulha de crochê
  • Enchimento
  • Olhos de segurança
  • Agulha de tapeçaria

Passo a passo

  1. Faça um círculo mágico.
  2. Trabalhe os pontos baixos em espiral.
  3. Faça aumentos para formar o corpo.
  4. Coloque o enchimento.
  5. Diminua os pontos para fechar.
  6. Faça os detalhes do personagem.
