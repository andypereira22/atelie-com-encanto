01
TUTORIAL

🕯️ Vela Aromática

Uma vela perfumada para deixar o ambiente mais agradável e acolhedor.

🧺 Materiais

  • Cera própria para velas
  • Pavio
  • Essência aromática
  • Recipiente adequado
  • Utensílios apropriados

✨ Passo a passo

Prepare o recipiente e fixe o pavio. Prepare a cera seguindo as instruções do fabricante.

Adicione a essência conforme a orientação do produto e despeje cuidadosamente no recipiente.

Aguarde a solidificação completa antes de finalizar.

02
TUTORIAL

🌸 Vela Decorativa

Uma peça delicada para deixar sua decoração ainda mais especial.

🧺 Materiais

  • Cera própria para velas
  • Pavio
  • Molde apropriado
  • Elementos decorativos

✨ Passo a passo

Prepare o molde e posicione o pavio corretamente.

Prepare a cera conforme as instruções do fabricante e coloque no molde.

Espere a peça solidificar e faça o acabamento decorativo.

03
TUTORIAL

🫙 Vela no Pote

Um projeto charmoso para criar uma vela artesanal em recipiente.

🧺 Materiais

  • Cera própria para velas
  • Pavio
  • Recipiente resistente e adequado
  • Essência opcional

✨ Passo a passo

Prepare o recipiente e fixe o pavio no centro.

Prepare a cera de acordo com as instruções do fabricante.

Despeje no recipiente e aguarde a solidificação completa.

TUTORIAL

🌿 Vela com Flores

Uma inspiração delicada para criar uma peça especial.

🧺 Materiais

  • Vela adequada para decoração
  • Flores decorativas apropriadas
  • Materiais próprios para fixação

✨ Passo a passo

Planeje a composição antes de começar.

Posicione os elementos decorativos de maneira harmoniosa.

Finalize verificando se todos os materiais são seguros para o uso pretendido.
